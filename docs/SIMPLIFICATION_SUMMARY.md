# Pipeline简化升级总结

## 概述

根据用户需求，对AI工具热点机会发现仪表板进行了重大简化，聚焦于**高质量数据精简**和**直接MVP生成**。

## 核心变更

### 1. 数据量精简（降低80% LLM成本）

| 数据类型 | 原来 | 现在 | 变化 |
|---------|------|------|------|
| AI工具 | 30个/天 | 10个/天 | -67% |
| 热点话题 | 100个/天 | ≤10个/天 | -90% |
| 痛点 | 55个/天 | 20个/天 | -64% |
| MVP机会 | Top 10 | Top 10 | 不变 |

**筛选策略：**
- **AI工具**：综合排序（新鲜度30% + 质量70%），Top 10
- **热点话题**：综合评分（质量70% + 热度30%），质量阈值≥60分，≤10个
- **痛点**：只从核心三源（HN + Reddit + GitHub）提取，按置信度Top 20

### 2. MVP建议简化

**原来（包含）：**
- 核心功能
- 目标用户
- 技术栈（Flask、Python等）
- 开发时间线（2周、1个月等）
- 成本估算（服务器、API费用等）

**现在（仅包含）：**
- 核心功能（3-5点）
- 目标用户群
- 变现方式建议（订阅制、定价区间）

**示例对比：**

```
【原来】
"开发一个基于AI的YouTube缩略图生成器，支持一键生成多种风格。
技术栈：Flask + Stable Diffusion API，预计2周MVP，
成本约$500/月（API费用$300 + 服务器$200）"

【现在】
"核心功能：1) AI驱动的YouTube缩略图生成器，支持多种风格模板，
2) 一键批量生成和A/B测试功能，3) 数据分析看板展示点击率。
目标用户：YouTube内容创作者、视频营销团队、MCN机构。
变现方式：免费增值模式，基础版免费（每月10张），
专业版$19/月（无限生成+高级模板），企业版$99/月（团队协作+API）。"
```

### 3. 架构简化：移除工具匹配步骤

**原来的流程：**
```
Phase 1: 数据抓取
Phase 2: 数据规范化
Phase 3: 数据去重
Phase 4: 提取痛点
Phase 5: 生成摘要
Phase 6: 匹配机会（匹配痛点与现有AI工具）⬅️ 移除
Phase 7: 评分机会                          ⬅️ 移除
Phase 8: 生成MVP建议                        ⬅️ 移除
Phase 9: 导出数据
Phase 10: 归档数据
```

**现在的流程：**
```
Phase 1: 数据抓取
Phase 2: 数据规范化
Phase 3: 数据去重
Phase 3.5: 数据筛选（Top 10工具、≤10热点、20痛点）⬅️ 新增
Phase 4: 提取痛点（只从核心源）              ⬅️ 修改
Phase 5: 生成摘要
Phase 6: 直接生成MVP机会（痛点+热点）       ⬅️ 新增
Phase 9: 导出数据
Phase 10: 归档数据
```

**关键区别：**
- 移除了"匹配现有AI工具"的逻辑
- MVP建议直接基于**痛点 + 热点**生成，不考虑市场上已有的工具
- 更聚焦于**创新性解决方案**而非模仿现有工具

## 代码修改清单

### 修改的文件

1. **src/llm/prompts.py** (Line 60-99)
   - 修改 `MVP_SUGGESTION_PROMPT`
   - 移除技术栈、时间线、成本估算要求
   - 强调产品概要（核心功能、目标用户、变现方式）

2. **src/llm/mvp_suggester.py** (Line 38-161)
   - 移除 `related_tools` 参数
   - 简化为只使用 `pain_point` + `related_topics`
   - 降低 `max_tokens` 从 1024 到 800

3. **src/models/opportunity.py** (整个文件)
   - 删除 `related_tools` 字段
   - 升级 `schema_version` 从 1.1 到 1.2
   - 更新注释和示例

4. **src/pipeline/orchestrator.py** (Line 65-723)
   - **新增方法**：
     - `_filter_top_tools()` - 筛选Top 10 AI工具
     - `_filter_top_topics()` - 筛选≤10热点话题
     - `_extract_pain_points_from_core_sources()` - 从核心源提取20个痛点
     - `_generate_opportunities_direct()` - 直接生成10个MVP机会
     - `_find_related_topics()` - 辅助：找到相关热点
     - `_calculate_opportunity_score()` - 辅助：计算机会评分
   - **移除方法**：
     - `_match_opportunities()` - 匹配痛点与AI工具
     - `_score_opportunities()` - 评分匹配结果
     - `_generate_mvp_suggestions()` - 为匹配结果生成MVP
   - **修改主流程** (Line 106-119)：
     - 添加 Phase 3.5（数据筛选）
     - 修改 Phase 4（只从核心源提取痛点）
     - 替换 Phase 6-8 为直接MVP生成

### 新增的文件

5. **test_simplified_pipeline.py** (新文件)
   - 验证Opportunity模型（v1.2，不含related_tools）
   - 验证数据筛选逻辑（Top 10工具、≤10热点）

## 预期效果

### 成本优化
- **LLM调用减少80%**
  - AI工具摘要：30个 → 10个（-67%）
  - 热点摘要：100个 → 10个（-90%）
  - 痛点提取+摘要：55个 → 20个（-64%）
  - MVP生成：10个不变，但tokens减少25%（1024→800）

- **预估月成本**（GPT-4o）
  - 原来：~$22.50/月
  - 现在：~$4.50/月（-80%）

### 数据质量提升
- **聚焦核心源**：HN（0.95）、Reddit（0.8）、GitHub（0.9）
- **质量阈值控制**：话题综合评分≥60分
- **精准筛选**：新鲜度+质量双重评分

### 产品价值提升
- **创新性增强**：不再模仿现有工具，直接从痛点生成新想法
- **商业导向**：MVP建议更聚焦变现方式和目标用户
- **实用性增强**：移除技术细节，更适合非技术创始人
